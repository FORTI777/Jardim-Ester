# Conferência dos versículos

Todos na **Almeida Revista e Corrigida (ARC)**.

Confira cada um na sua Bíblia antes de publicar. Se alguma palavra estiver
diferente, corrija direto no arquivo `js/textos.js`, na seção VERSÍCULOS,
no campo `texto` do versículo correspondente. A chave entre colchetes é o
nome do campo lá dentro.

Este arquivo **não vai para o site publicado**.
